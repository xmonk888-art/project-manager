# 首次使用与任务推进排查

| 现象 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 技能未出现 | 目标宿主的发现目录、三个运行文件及同名副本 | 按安装说明确认；必要时重启后检查，不把名字出现在提示词里视为发现成功 |
| 没有实际派工 | 当前是否为讨论或只读；任务是否需要；宿主是否提供并允许子助手 | 明确执行范围；没有委派能力时串行处理，并如实报告 |
| 缺少专业技能或工具 | 项目规范与通用能力是否足以满足交付和验收 | 继续可验证部分；不足再调研替代，不自动安装 |
| 只给计划，未交成果 | 当前阶段、已有执行授权、输入及依赖是否齐全 | 在已有授权内继续到交付；实际缺口说明影响与可选处理 |
| 续作时重复旧任务 | 当前状态、版本替代关系和已有成果证据是否一致 | 核对后从未完成处继续，复用有效检查 |
| 换电脑后不能复跑 | 路径、软件、字体、专业技能及连接是否恢复 | 分成已可做、需替代、待补条件；原电脑通过不等于本机通过 |

这些是排查入口，不代表宿主具备上述全部能力。未发现实际原因时保留未知，不把推测写成确认故障。
